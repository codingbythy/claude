# claude

- `index.html` — turn-based strategy game
- `cozy-cabin/` — Stargazer's Cabin: an animated sleep scene (falling snow, occasional lightning, firelight) with generated wind, fire and thunder sounds. Open `cozy-cabin/index.html` in a browser.
- `lighthouse-room/` — Cartographer's Cottage: rain on the window, a rolling sea, a turning lighthouse beam and occasional lightning, with rain, sea, wind and thunder sounds.
- `tools/` — shared pipeline that turns any scene into a seamless loop and a long-video kit (see `tools/README.md`).
